## Failures hit and fixed the same day

| exec | failure | root cause | fix |
|---|---|---|---|
| #1 (refresh) | `Invalid wait amount` | Route dropped `poll_seconds` on loop-back | Route re-attaches config each iteration (commit 6fc4384) |
| #4, #5 (report) | `access to env vars denied` at Config | n8n blocks `$env.*` in nodes by default | `N8N_BLOCK_ENV_ACCESS_IN_NODE=false` in n8n/start_n8n.cmd |
| - | fresh empty n8n instance after restart | n8n 2.x nests `.n8n` under `N8N_USER_FOLDER` | pin the var at the install's `data` dir |

Both regressions are pinned by `tests/test_n8n_workflows.py`.
