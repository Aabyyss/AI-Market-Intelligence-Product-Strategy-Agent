AI Market Intelligence & Product Strategy Agent

A Python pipeline that watches Hacker News, builds a RAG knowledge base over what it finds, and runs a five-agent LLM team to produce an evidence-cited market report — scheduled and orchestrated by n8n, verified by CI on every push.

CI green — 96 tests + gated retrieval eval Python · FastAPI · FastEmbed · sqlite-vec · n8n · Docker

Architecture

Hacker News ──▶ fetch (retries transient failures) ──▶ clean → chunk → embed (bge-small, FastEmbed) ──▶ SQLite + sqlite-vec (83 posts / 115 chunks) ──▶ retrieval ──▶ agents: Research → Competitor → Customer/UX → Strategy → Critic ──▶ typed JSON report + citation audit ──▶ FastAPI /ask · /reports · /pipeline/refresh · /eval ──▶ n8n schedules: corpus refresh 06:00 · report 07:00 → Slack

RAG, not vibes

Every agent claim must cite a retrieved chunk; answers refuse to assert what the corpus doesn't support.

Typed agent outputs

Agents emit structured JSON (claims + citations + verdicts), so the critic and the report render from data, not free-text markdown.

Evaluated retrieval

A labeled question set scores the index on every push; below-threshold retrieval fails the build.

The citation audit catches hallucinated sources

The report's citation health is checked mechanically by code, not by an LLM. On a live run the model cited a source that didn't exist — and the audit caught it:

Reference [10] — unresolved: report cites 10 sources, 9 evidence posts retrieved. Verdicts: 1 supported · 3 partial · 10 unsupported.
Mechanical audit: every [n] must point at real evidence; health is aggregated per report section and surfaced in the rendered output and the Slack summary.
