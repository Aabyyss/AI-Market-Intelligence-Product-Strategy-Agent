03 · five agents, one job each

Grounded in retrieval — never raw text

$ python run_report.py "fees and developer payouts"
  research   : 9 queries planned → 15 posts retrieved
  competitor : shopify 5 · woocommerce 5 · bigcommerce 5
  customer   : pain points · praise · switching themes
  strategy   : ranked opportunities + risks, cited
  critic     : 5 supported, 6 partial, 9 unsupported
  citations  : 15 in-range, 0 out-of-range
  warning    : 1 competitor claim has no citation
  report     : data/reports/market_report.md
Anti-hallucination, in layers
1 · model sees numbered evidence only
2 · every claim must cite [n]
3 · critic judges support claim by claim
4 · code verifies each [n] was really retrieved
Output is typed, not prose
{ "claim": "...", "citations": [2,6] }
verdicts keyed by claim id · retried once
invalid JSON → free text, flagged in the audit
04 · the deliverable

Every claim points at a post you can open

Developers are unhappy with the revised revenue share and are considering building for other platforms [3, 11]
critic · SUPPORTED — both sources describe the payout change and the reaction
Shopify offers a generous payout program, twice a month [3]
critic · PARTIAL — [3] is a sarcastic complaint about cuts, not a program description
15
evidence posts, all cited in range
5
claims judged fully supported
6
partial — flagged for a human
9
unsupported — dropped, not shipped

The critic is a small local model and it is not always right — which is exactly why verdict counts are computed from typed data in code, never from the model's own arithmetic.

06 · shipped

Python for the intelligence.
n8n for the business workflow.

Service
POST /reports → 202 job
GET /jobs/{id} → status
POST /search · /ask · /eval
GET /health → corpus + provider
Deploy
docker compose up --build
model baked into the image
sqlite-vec smoke-tested at build
secrets from env, never in git
Schedule
06:00 refresh corpus
07:00 generate report
poll → find a failed report
Slack: verdicts + citation health

Read reports critically: a 3B local model writes generic prose and over-flags some supported claims. The architecture is provider-agnostic — swap in a bigger model and the same numbers get better.
